# Synthetic examples

This directory tests the software workflow only. **It contains no real cells, compounds, or biological measurements.**

`sample.json` uses a fictional compound identity. The four 64 × 64 PNG files contain geometric shapes.
The values in `cp.csv` are manually specified; they were not measured by running CellProfiler on these images.
Relative paths in the input file resolve from the directory containing `sample.json`.

Run these examples in the default `mock` mode. For a live run, supply your own compound identity, experimental conditions,
treatment/control images, and CP table. Do not submit the fictional identity in this directory to online databases.

Developer-authored inputs, prompts, model-facing metadata, visible rationales, generated narratives, reports, and audits must use English.
External source titles, identifiers, and quotations retain their original content, with English explanations where needed.
Visible rationales are evidence summaries; the API does not expose or verify the language of private model reasoning.
Historical API records remain unchanged. Translating a local report does not require another paid model request.
